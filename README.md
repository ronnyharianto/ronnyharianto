## ⭐ Featured projects

> All personal builds, none of them tutorials.

### [fintracko](https://github.com/ronnyharianto/fintracko) — multi-tenant financial tracking SaaS

Built because my family needed a better way to track money. Workspaces with OWNER/COLLABORATOR roles and email invites, multi-currency accounts, recurring budgets with utilization tracking, two-level categories, income/expense/transfer transactions, and a dashboard with analytics. OAuth-only auth (Google + GitHub), mandatory onboarding with ToS acceptance, SEO-ready public site with OpenGraph and JSON-LD.

`Next.js 16` `React 19` `TypeScript` `Prisma` `PostgreSQL (Neon)` `Better Auth` `Tailwind CSS 4`

### [BuffCore](https://github.com/ronnyharianto/BuffCore) — reusable .NET foundation libraries, on NuGet

The .NET conventions I kept rewriting at work, packaged once for everyone: response envelopes & paging contracts, EF Core entity/audit conventions with soft delete, permission + API-key authorization, JWT claims mapping, and injectable Google Cloud Storage / Firebase Cloud Messaging helpers. Small, independently versioned packages, shipped with tests and CI-based packing.

`C#` `.NET` `EF Core` `NuGet` `Clean Architecture` `CI/CD`

### [reverse-image-search](https://github.com/ronnyharianto/reverse-image-search) — copyright-risk screening for website images

Enter a website URL → the app crawls its pages with Playwright, extracts and validates images with Sharp, runs real reverse image search per image, and streams results live into the UI while the scan is still running. Comes with getting-started docs, a test suite, and a detailed README.

`TypeScript` `Next.js` `Playwright` `Sharp` `Automated Testing`

### [play-pass-go](https://github.com/ronnyharianto/play-pass-go) — pass-and-play property trading game

One device, 2–4 players, no install: buy, rent, trade, and build your real-estate empire in the browser. Custom game engine with chance cards. The family game night that got out of hand. **Live: [play-pass-go.vercel.app](https://play-pass-go.vercel.app)**

`TypeScript` `Next.js` `React` `Game Engine` `Vercel`
